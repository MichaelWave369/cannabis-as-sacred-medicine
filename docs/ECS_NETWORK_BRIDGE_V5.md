# ECS Network Atlas companion · v1

This React component reads the `ecs-network` domain from the existing Cannabiverse Research Bridge v2 manifest, with an additive content release 5.0.0. Cannabiverse remains the only evidence authority; Sacred Medicine is a **read-only** educational consumer. There is no duplicated medical dataset and no Zenodo paper/PDF mutation.

The component displays scientific source citations, research context and claim boundaries. AEA/2-AG are endogenous; Δ9-THC/CBD are plant-derived. Clinical outcomes remain formulation- and population-specific; neither receptor expression nor philosophical reverence establishes treatment effectiveness.

Deployment dependency: merge and deploy **Cannabiverse ECS Network Atlas PR** first. If the ECS domain is absent, unavailable or incompatible, this component displays an explicit unavailable message rather than an invented claim.

Validation: `npm run check:ecs-network`, `npm run check:bridge`, `npm run build`.

The existing historical/spiritual/testimony sections and the published v1.0.1 paper are untouched.
