# Sacred Medicine Pain & ECS bridge v3

The public navigator loads the **second research domain** from Cannabiverse via the existing versioned bridge manifest `data/bridge/research-index-v2.json`. The transport contract stays at `2.0.0` because the interface is backwards compatible. The new domain has ID `pain-ecs`, source dataset ID `cannabiverse-pain-ecs-evidence`, and its own source citations.

Separate lanes distinguish human clinical findings, harms, insufficient evidence, professional guidance, and experimental ECS physiology. A balanced THC/CBD preparation is a **multi-compound formulation**: neither compound alone inherits its outcome just because both links appear.

Sources include AHRQ 2025, IASP 2021, receptor mechanism reviews and the NIH NCCIH safety page. No treatment advice is given. Missing or incompatible science feeds fail closed. Neither the original Zenodo work nor its PDFs are revised by this web update.

CI: `npm run check:bridge`, `npm run check:pain-ecs`, and `npm run build`.
